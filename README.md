# Ink & Marbles

A doodle physics puzzle. Draw ink lines on graph paper to guide falling marbles into the cup.

- Draw with mouse or finger, then press **Drop** (or Space).
- Red spikes pop marbles. Ink won't stick in hatched zones or on walls.
- Use less ink for more stars. 10 pages; progress saves in your browser.

Open `index.html` in any browser. No build step, no dependencies.
